# ADR-002: 데이터 소스로 championsbattledata.com 공개 API 채택, 스크래핑 배제

- 상태: 채택 (2026-09-22)
- 관련: Phase 2, `CLAUDE.md` 8장, `app/ingestion/`
- 기록: 소급 작성 (2026-11-03). 약관 원문 대조는 이 날짜에 수행했다.

## 맥락

이 서비스는 "사람들이 무엇을 고르는가"(사용률, 아이템·성격·기술 채용률, 정석 샘플)를 외부에서
가져와야 한다. 종족값·기술 위력·타입 상성 같은 **계산의 입력이 되는 값은 수집 대상이 아니다** —
그건 우리 엔진이 계산하거나 시드 데이터로 직접 관리한다. 수집이 깨져도 계산 기능은 100%
살아 있어야 하므로, 외부 의존의 표면적을 최소로 줄이는 게 전제였다.

문제는 포켓몬 챔피언스의 메타 통계를 어디서 얻느냐였다. 한국어권에는 정리된 공개 소스가 없었고,
op.gg나 champs.pokedb.tokyo 같은 사이트는 화면에 통계를 띄우지만 API를 공개하지 않는다.

데이터 소스를 찾던 중 championsbattledata.com이 **공개 JSON API를 제공한다는 사실을 발견했다.**
스크래퍼를 만들려다 대안을 찾은 것이 아니라, API를 찾는 과정에서 나온 결과다.

## 선택지

### A안: championsbattledata.com 공개 JSON API
- 장점:
  - 구조화된 JSON이라 파싱이 안정적이다. HTML 구조 변경에 깨지지 않는다.
  - 폼별 종족값·타입·특성(metadata)까지 제공해 마스터 시드 부트스트랩에 쓸 수 있다.
  - 일별 스냅샷과 포맷(Singles/Doubles) 구분을 제공한다.
  - 제공자가 API로 쓰라고 공개한 것이므로 이용 의사가 명확하다.
- 단점:
  - 비공식 팬 사이트 한 곳에 의존하게 된다. 운영이 중단되면 메타 기능이 멈춘다.
  - 약관이 영구 미러·아카이브를 금지하므로 캐시를 보존 기간 있는 구조로 설계해야 한다.
    무한 누적 스냅샷 테이블을 만들 수 없다.
  - 기술 위력·명중·PP는 제공하지 않아 별도로 관리해야 한다.
  - "as is" 제공이며 완전성·정확성·가용성을 보장하지 않는다. 엔드포인트도 예고 없이 바뀔 수 있다.

### B안: op.gg / champs.pokedb.tokyo HTML 스크래핑
- 장점:
  - 소스를 복수로 확보해 한 곳이 죽어도 대체할 수 있다.
- 단점:
  - HTML 구조가 바뀌면 조용히 깨진다. 유지보수 비용이 계속 든다.
  - 운영자가 공개 이용을 의도하지 않은 경로로 데이터를 가져가는 행위다.
  - 폼체인지 포켓몬 중복 같은 파싱 함정이 많다.

### C안: 자체 수집 (배틀 로그 직접 집계)
- 장점:
  - 외부 의존이 사라진다.
- 단점:
  - 이용자 규모가 없는 상태에서 통계적으로 의미 있는 표본을 만들 수 없다. 출발점에서 불가능하다.

## 결정

- **championsbattledata.com 공개 API를 주 소스로 채택한다** (A안).
- **스크래핑은 Phase 2 범위에서 제외한다.** op.gg / champs.pokedb.tokyo는 보조 소스 후보로만 남긴다.
- 약관 준수를 설계 제약으로 받아들인다 — 보존 기간 있는 캐시, 원본 통계를 그대로 반환하는
  공개 엔드포인트 금지, 통계 표시 화면마다 출처 표기.
- **요청 간 최소 1초 지연, 동시성 1을 스스로 건다.** 약관에 고정 rate limit은 없지만
  과부하 시 차단 가능성이 명시돼 있어, 상대 서버에 부담을 주지 않는 쪽으로 자율 규제한다.

## 근거

(2026-11-03, 개발자 본인 기록)

**어떻게 선택했는가**
스크래핑을 하려다 대안을 찾은 게 아니라, **API를 찾아보던 중에 이 사이트를 발견했다.**

**스크래핑을 배제한 이유**
윤리적인 이유다. 내가 찾은 사이트도 공식 포켓몬 사이트가 아니라 **외국 개발자가 정리해놓은
사이트 같아서** 그랬다. 개인이 만들어 공개한 것을 동의 없이 긁어오는 건 하고 싶지 않았다.

**약관은 언제 확인했는가**
쓰기로 결정한 뒤에 확인했다. 순서가 반대였다.

## 포기한 것

- **소스 다양성.** 단일 비공식 사이트에 메타 데이터 전체를 걸었다. 운영이 멈추면 대체 경로가 없다.
  계산 기능은 살아남도록 설계했지만, 메타 기반 기능(선출 추천의 상대 샘플 가정, 아키타입 인식)은
  "무보정 가정" 폴백으로 품질이 떨어진 채 동작하게 된다.
- **데이터 영속성.** 영구 미러 금지 때문에 과거 메타의 장기 추이를 축적할 수 없다.
  "작년 이맘때 메타와 비교" 같은 기능은 구조적으로 불가능해진다.
- **수집 속도.** 요청 간 1초·동시성 1을 스스로 걸었으므로 대량 갱신에 시간이 걸린다.
- **원본 통계 노출.** 우리 API는 계산 결과와 분석만 반환할 수 있다.
  "통계 API를 공개한다"는 제품 방향은 약관상 닫혀 있다.

## 되돌리는 조건

- **제공자 운영 중단 또는 접근 차단**: API가 장기간 응답하지 않거나 차단되면 보조 소스
  (op.gg / champs.pokedb.tokyo)를 재검토한다. 이때도 스크래핑 윤리 판단은 다시 한다 —
  "대안이 없으니 어쩔 수 없다"로 자동 통과시키지 않는다.
- **약관 변경**: 상업적 이용 허용 조항이 철회되거나 출처 표기 요건이 강화되면 즉시 재검토한다.
- **유료화 검토 시점**: `/api-rules/`는 상업적 이용을 명시적으로 허용하지만 `/license.html`은
  "personal, educational, and competitive analysis use"라고 더 좁게 적고 있다. 두 페이지가
  어긋나므로, 유료 티어를 실제로 도입하기 전에 운영자에게 서면 확인을 받는다.
- **공식 API 등장**: 포켓몬 측이 공식 통계 API를 제공하면 그쪽으로 옮긴다.

## 참고 — 약관 원문 대조 (2026-11-03 확인)

`/api-rules/` 기준으로 아래가 명시돼 있다. `CLAUDE.md` 8-2의 항목이 실재함을 확인했다.

- 출처 표기: "Battle data provided by Pokémon Champions Battle Data" + 링크
- 금지: 재판매·재라이선스·재배포, 경쟁 공개 API / DB 덤프 / 대량 다운로드 / 유료 데이터 피드,
  원본 응답 접근권 판매, 자체 원본 데이터처럼 제시, **캐시로 영구 미러·아카이브·API 대체물 구성**
- 캐싱: 성능 향상과 반복 요청 감소를 위한 합리적 범위에서 허용
- rate limit: 고정된 공개 제한 없음. 과도한 부하·규칙 위반 시 제한·차단·취소 가능
- **상업적 이용: 허용** (유료 앱·웹사이트·도구·대시보드·영상·기사·서비스 포함)
- 공식 승인·후원 암시 금지. 제3자 자산(포켓몬 이름·이미지·게임 데이터·상표) 권리는 부여하지 않음
